# smeltery-core

The HTTP kernel of [Smeltery](https://github.com/smelteryworks/smeltery): routing, typed configuration from `.env`, the
application container, middleware, error pages, the server with graceful shutdown, the console kernel and the test
client.

Apps use it through the `smeltery` crate, which re-exports everything here. See the
[Smeltery README](https://github.com/smelteryworks/smeltery#readme) for the manual.
